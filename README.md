# Model Inference Deployment Skill

Reusable guidance for rollback-safe model inference deployments across clouds, runtimes, accelerators, and serving frameworks.

- Skill entry point: [`SKILL.md`](SKILL.md)
- Public-cloud example: [Qwen3.8-27B W8A8 on Huawei Cloud ModelArts Standard](examples/qwen38-modelarts-public-cloud/README.md)

The example uses placeholders for every account-, project-, region-, network-, storage-, image-, and endpoint-specific value. It does not contain customer credentials or private-cloud addresses.
